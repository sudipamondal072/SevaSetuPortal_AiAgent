AGENT MCP ENDPOINTS
-------------------
Citizen MCP, streamable HTTP:   http://localhost:8001/mcp
Officer MCP, streamable HTTP:   http://localhost:8002/mcp
Citizen OAuth resource metadata:
                                http://localhost:8001/.well-known/oauth-protected-resource/mcp
Officer OAuth resource metadata:
                                http://localhost:8002/.well-known/oauth-protected-resource/mcp
Citizen server tool surface:    pension_scheme_information
                                submit_pension_application
                                check_my_application
Officer server tool surface:    list_pending_applications
                                review_application
                                decide_on_application

--------------------------

Portal signing keys:            http://localhost:8000/.well-known/jwks.json
Dynamic client registration:    http://localhost:8000/oauth/register
Authorization:                  http://localhost:8000/oauth/authorize
Citizen/officer portal sign-in: http://localhost:8000/oauth/login
Consent screen:                 http://localhost:8000/oauth/consent
Token exchange/refresh:         http://localhost:8000/oauth/token
Token revocation:               http://localhost:8000/oauth/revoke
Connected applications:         http://localhost:8000/status/connections

AGENT PORTAL API ROUTES
-----------------------
Current official scheme rules:  http://localhost:8000/api/agent/scheme
Citizen's own application:      http://localhost:8000/api/agent/citizen/application
Submit citizen application:     http://localhost:8000/api/agent/citizen/applications
Officer pending queue:          http://localhost:8000/api/agent/officer/applications
Officer case details:           http://localhost:8000/api/agent/officer/applications/<application_id>
Officer decision:               http://localhost:8000/api/agent/officer/applications/<application_id>/decision

PORTAL PAGES AFTER SUBMISSION
-----------------------------
Application details:            http://localhost:8000/application/<application_id>
Officer application details:    http://localhost:8000/admin/application/<application_id>
Acknowledgment PDF:             http://localhost:8000/ack/<application_id>.pdf

Deployment note: replace localhost and ports with the exact public HTTPS hostnames
and routes configured for that deployment. Keep citizen and officer MCP resources
distinct, and issue OAuth tokens for the exact matching resource URL.
